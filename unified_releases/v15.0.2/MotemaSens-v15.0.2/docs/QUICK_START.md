# MotemaSens v15.0.2 quick start

1. Install `motemasens-mobile-v15.0.2.apk` on the Android phone.
2. Turn on MotemaSens and wait for the display to finish starting.
3. Connect by BLE for setup, or use Local mode when the phone and device are
   on the same WiFi network.
4. Check that ECG, MIC, IMU and SD show as ready.
5. Open **Storage**, choose the signals, and start **Write to SD card**.
6. Keep the device still and correctly placed during the recording.
7. Stop recording before browsing, downloading, renaming or deleting files.
8. Review the recording result. Do not use a `FAILED` or `UNVERIFIED` file for
   timing or waveform analysis.
9. Download the `.bin` file and use the v15.0.2 BIN-to-CSV or MATLAB tool.

Keep the device powered while updating. Update the Android app before updating
device firmware.
